## Overview

Nintendo.com circa 2001 is the web rendered as **console hardware**. An interface where every panel is a **beveled metal plate** in brushed periwinkle (`#7a8aba`), edge-lit on top and shadow-lined with Chrome Indigo (`#3d4f97`) below — treating the web page like the faceplate of a game system.

The system runs on a tight three-voice contrast:
1. **Structural Voice**: Cool periwinkle-to-indigo chrome (`#7a8aba`, `#8ba1d4`, `#3d4f97`).
2. **Authority Voice**: Carbon navy (`#21242e`) — top nav bar, action buttons, footer, printed with halftone dot texture.
3. **Energy Voice**: Reserved for directional signal only:
   - **Nintendo Red** (`#e60012`): Racetrack logo pill, alert
   - **Signal Orange** (`#f68d1f`): Forward cues, submit, "Bắt đầu tạo"
   - **Amber** (`#ecab37`): Utility buttons, badges, chips
   - **Nav Gold** (`#e48600`): Top-nav menu links
